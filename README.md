# AI-Resume-Intelligence

AI-powered Resume Intelligence and Job Matching system.

## Project Structure
- `notebooks/`: Jupyter notebooks for EDA, preprocessing, OCR, NLP, modeling.
- `src/`: Source code for all components.
- `data/`: Local dataset storage (ignored in git).
- `app/`: Backend/API deployment.
- `configs/`: Configuration files.
- `tests/`: Unit and integration tests.

## Phase 1
- Exploratory Data Analysis (EDA) of the Hugging Face resume dataset.
